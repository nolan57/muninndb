# Y2038 Problem Fix Documentation

## Problem
`Association.LastActivated` and `RestoredAt` use `int32`, which will overflow in 2038.

## Implemented Fix

### 1. Storage Structure Fix
**File**: `internal/storage/types.go`

```go
type Association struct {
    // ...
    LastActivated     int64   // Unix seconds (int64 to avoid Y2038 problem)
    // ...
    RestoredAt        int64   // Unix seconds (int64 to avoid Y2038 problem)
}
```

### 2. Encoding/Decoding Compatibility Layer
**File**: `internal/storage/association.go`

To maintain backward compatibility, encoding uses `uint32` (safe before 2038), but in-memory uses `int64`:

```go
// encodeAssocValue - encoding conversion
func encodeAssocValue(..., lastActivated int64, ...) {
    // Safe conversion: values before 2038
    var lastActivated32 uint32
    if lastActivated > 0 && lastActivated < math.MaxInt32 {
        lastActivated32 = uint32(lastActivated)
    }
    binary.BigEndian.PutUint32(val[14:18], lastActivated32)
}

// decodeAssocValue - decoding conversion
func decodeAssocValue(...) (..., lastActivated int64, ...) {
    lastActivated = int64(binary.BigEndian.Uint32(val[14:18]))
}
```
